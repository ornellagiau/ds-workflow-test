# docs-assets/

Files the docs site serves from its root (`staticDirs` in `.storybook-docs/main.js`).

| Path | What |
|---|---|
| `fonts/inter-latin-wght-normal.woff2` | The font **Inter** (variable, Latin), used by the docs site |
| `fonts/inter.css` | The `@font-face` rule |
| `fonts/Inter-OFL-LICENSE.txt` | The license of Inter (SIL Open Font License 1.1). Keep it next to the font |

The font is served from the site itself, not from Google Fonts, so no visitor data goes to a third party. The docs font is a choice for readability and is not one of the SZ brand fonts.
