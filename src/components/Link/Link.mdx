# Link

> **Status: draft.** Generated from `Link.contract.yaml`. Hover, press and tab to see the states. Needs review.

<Canvas of={LinkStories.Primary} />

## Purpose
Text link that goes somewhere else (another page or view).

## When not to use
- Actions on the current page. Use Button.

## Emphasis
| Emphasis | Use |
|---|---|
| `primary` | Default link with an accent underline. |
| `secondary` | Dark underline. |
| `quiet` | Underline only on hover. Use only in link lists (footer, navigation). |

## Props
| Contract | In code | Type | Default |
|---|---|---|---|
| `text` | `children` | string | `Hier einloggen` |
| `size` | `size` | `S` / `M` | `S` |
| `emphasis` | `emphasis` | `primary` / `secondary` / `quiet` | `primary` |
| `leading_icon` | `leadingIcon` | slot, optional | `null` |
| `trailing_icon` | `trailingIcon` | slot, optional | `null` |
| `href` | `href` | string, not visible | required |
| `disabled` | `disabled` | boolean | `false` |

## Accessibility
- **role:** link
- **keyboard:** Tab moves focus to the link, Enter follows the link
- **accessible name:** the visible text
- **focus indicator:** 2px ring outside, Color/Border/Highlight
- **target size:** S 18px high, M 20px high
- **disabled:** aria-disabled, not followed

## Open
- **set:** low contrast, no Link focus token
- **focus indicator:** 1.3:1 light, 1.9:1 dark
- **target size:** below 24px, inline links are exempt

## Assumed, not in Figma
- `href`: not in Figma
- `disabled`: Figma has State=Disabled
- `states`: set by interaction, not by the author
- `keyboard`
- `accessible_name`
- `disabled`
