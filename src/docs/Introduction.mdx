# DS workflow test

One place for docs and live previews. Docs are written here and nowhere else.

## Index
- **Foundations/Color tokens**: all color tokens, generated from Figma via `tokens/tokens.json`.
- **Components/Button**: actions on the current page (`primary`, `secondary`).

## How this works
1. Token values live in Figma → exported to `tokens/tokens.json` (`figma/export-tokens.js`).
2. Component docs are one `.mdx` file per component, next to the code.
3. The `figma-description` lines in each `.mdx` are copied into Figma (`figma/sync-descriptions.js`).
