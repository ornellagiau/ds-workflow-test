# Token naming

Every color token follows one pattern:

`{Component}/{Element}/{Role}/{State}`

Example: `Button/Surface/Primary/Idle`.

Four global tokens add a fifth slot, **Variant**: `Color/Content/Primary/Idle/Default` and `Inversed`, `Color/Content/Secondary/Idle/Default` and `Inversed`.

Multi-word names are written in PascalCase in the CSS variables. The rest of the CSS naming rule still needs to be defined.

| Slot | Question it answers | Words in use |
|---|---|---|
| Component | Where is it used? `Color` means global: use it anywhere. | Color, Audio Player, Button, Card, Checkbox, Chip, Header, Input, Label, Link, Modal, ProductSwitch, Progress Indicator, Radio, Switch, Tag, Teaser, Toggle |
| Element | What is colored? | Background (global fills and the real background of a component), Surface (the other fills inside components), Border, Content (text and icons), Logo |
| Role | What is the function or style? | Primary, Secondary, Tertiary, Highlight, Ghost, Inversed, Strong, Live, Opinion, Exclusiv, Transparent, Modal Background |
| State | Which state? | Idle, Hover, Active, Focused, Selected, Disabled, Error, Warning, Success |
| Variant | Which version of the same token? Only on `Color/Content` Primary and Secondary. | Default, Inversed |

Light and dark are not part of the name. They are modes of the same token.

## Rules
1. Use a global `Color/*` token first. Use a component token only inside its component.
2. Never use a primitive in a component.
3. Empty slots are skipped. `Color/Background/Error` has no Role. `Toggle/Surface/Active` has no Role.
4. Error, Warning and Success are States, never Roles.
5. A word always sits in the same slot. The one exception is `Inversed`, see below.
6. No hyphens. Multi-word names keep their spaces in Figma: `Audio Player`, `Modal Background`. PascalCase is applied only when the CSS variables are generated.
7. Background is for global tokens (`Color/*`) and for the real background of a component, if it has one. Surface is for the other fills inside components. A component can have both.

## Good to know
- Toggle and Switch are separate components.
- Toggle and Progress Indicator use both Background and Surface on purpose. Background is the real background (for example the track), Surface is the rest.
- `Inversed` is a Role in `Color/Background/Inversed` and a Variant in `Color/Content/Primary/Idle/Inversed`.
- `ProductSwitch` is currently written without a space.
