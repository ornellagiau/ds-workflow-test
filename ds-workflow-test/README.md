# DS workflow test: cost-free design system pipeline

Figma (values) → GitHub (docs + code) → Storybook on GitHub Pages (team view) → Claude (reads the repo).

## Setup (about 15 min)
1. Create a **public** repo on your personal GitHub account (GitHub Pages is free only for public repos). Use mock data only, no internal SZ content.
2. Upload this folder's contents to the repo (drag and drop in the GitHub web UI works, or `git push`).
3. In the repo: **Settings → Pages → Source: GitHub Actions**.
4. The workflow runs on every push. Your Storybook appears at `https://<user>.github.io/<repo>/`.
5. In Claude: connect the **GitHub** connector and point it at the repo. `CLAUDE.md` tells it where to look.

## Local
```
npm install
npm run storybook
```

## Where things live
| What | File | Edited by |
|---|---|---|
| Token values | `tokens/tokens.json` | Exported from Figma with `figma/export-tokens.js` |
| Component docs | `src/components/*/*.mdx` | You (AI drafts, you review) |
| Token doc page + CSS | `src/docs/Tokens.mdx`, `src/tokens.css` | Generated by `npm run tokens` |
| Figma descriptions | `figma/descriptions.json` | Generated from MDX, synced with `figma/sync-descriptions.js` |
| Figma ↔ code mapping | `figma/component-map.json` | You (when components change) |

## Flow
- **Token change:** change the variable in Figma → ask Claude to export to `tokens/tokens.json` → PR → merge → Storybook updates.
- **Doc change:** edit the `.mdx` → PR → merge → Storybook updates → ask Claude to run `figma/sync-descriptions.js` in Figma.
